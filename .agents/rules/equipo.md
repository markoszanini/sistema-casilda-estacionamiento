# Reglas de Coordinación de Equipo (Estacionamiento Inteligente)

Esta es una regla global para todas las IAs que asistan a los miembros de este equipo.

## Contexto del Proyecto
Estás trabajando en el módulo "Estacionamiento Inteligente" para Casilda. El equipo consta de 1 Ingeniero (Líder/LPR), 1 Diseñador (UI/UX), 1 Dev Backend (Python/Django) y 1 Dev Frontend (React Native).

## Instrucción Obligatoria para la IA
Cada vez que interactúes con tu usuario:
1. **Identificación de Rol:** Si aún no sabés qué rol cumple tu usuario humano (Ingeniero, Diseñador, Dev 1 o Dev 2), PREGUNTÁSELO en tu primera respuesta. 
2. Una vez que sepas su rol, DEBES leer el archivo `task.md` ubicado en la raíz del proyecto para revisar el estado general del equipo y decirle qué tareas tiene pendientes.
3. Si detectás que el usuario está a punto de trabajar en algo bloqueado por otro rol, advertíselo.
4. Si el usuario completa una tarea, actualizá el `task.md` marcándola con `[x]` para que cuando hagan `git push`, las otras IAs vean el progreso.
5. Leé el `informe_equipo.md` si necesitás contexto adicional.
